# Permissions needed for Laserfiche SharePoint Integration

| Right                           | Required To                                                                                           | Notes                                                                                                     |
| ------------------------------- | ----------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------- |
| Read                            | - Use repository browser <br/> - Save documents to Laserfiche (that don't replace document with link) | - You can use all functionality of integration EXCEPT "Replace with link" and Administrator Configuration |
| Contribute                      | - Save documents to Laserfiche that replace document with link                                        |                                                                                                           |
| Manage Permissions/Full Control | - Configure mappings required for integration to function                                             | - Administrator needs to configure mappings before anyone can use the integration                         |
